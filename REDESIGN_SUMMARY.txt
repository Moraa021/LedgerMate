🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ISSUE: Styles not loading
SOLUTION:
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Check CSS file path in base.html
  3. Verify static folder configuration in app.py
  4. Restart development server

ISSUE: Mobile menu not working
SOLUTION:
  1. Check JavaScript is loaded
  2. Open browser console (F12)
  3. Look for JavaScript errors
  4. Verify mobile menu toggle ID matches

ISSUE: Accessibility warnings
SOLUTION:
  1. Use axe DevTools to identify issues
  2. Add missing aria-labels
  3. Check color contrast ratios
  4. Verify keyboard navigation works

ISSUE: Slow performance
SOLUTION:
  1. Optimize images (use WebP)
  2. Enable Gzip compression
  3. Minify CSS/JS in production
  4. Use CDN for static files
  5. Enable browser caching
